# Architectural Decision Records (ADRs)

This directory stores formal Architectural Decision Records capturing fundamental structural choices, trade-offs, technology evaluations, and 10x defensible moats.

## Standards
- Authored by the System Architect (`[System Architect]`) when significant trade-offs occur (e.g. database selection, auth protocol, distributed vs local state).
- Hardened through the 5-Advisor Claude Council (`claude-council`).
- Indexed automatically in `INDEX.md`.
