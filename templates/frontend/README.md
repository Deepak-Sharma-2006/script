# Frontend Design Tokens & UI Scaffolding

This directory contains standardized semantic design tokens required by Rule 14 ("Enterprise Frontend Component Shell & Design Token Invariant").

## Assets
- `design-tokens.css`: Core CSS custom properties defining typography scales, dark-mode color palettes, border radii, spacing increments, and elevation shadows.

## Usage
Import `design-tokens.css` into all web interfaces to ensure cohesive typography, dark mode palettes, and component shell styling without ad-hoc hex codes.
