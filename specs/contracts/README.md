- Formalize public data contracts (`data_schemas`) prior to implementation.
- Enforce explicit FSM transitions (`fsm_states`, `fsm_transitions`) to prevent illegal lifecycle states.
- Serve as the ground-truth contract against which the Adversarial SDET builds red-phase test harnesses.
