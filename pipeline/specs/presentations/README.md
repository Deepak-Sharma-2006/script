# Presentation & Pitch Deck Artifacts Directory

This directory stores presentation pitch decks, slide manifests, and visual assets generated by the OmniDeck engine (`python -m scripts.orchestrator.task_dispatcher --task presentation`).

## Purpose & Protocols
- **Stage 1 (PPTX)**: High-speed compilation (<0.2s) of native `.pptx` presentation files adhering to 2D Flex/Grid geometry and 7 visual primitives.
- **Stage 2 (PDF Export)**: Gated rendering executed only upon explicit operator command (`--export-pdf`).
- **Clean State**: Presentation files generated during project pitches should reside here.
