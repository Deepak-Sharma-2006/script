# Product Specifications & Requirements Directory

This directory stores project-level specifications, problem statements, and requirements artifacts used by the autonomous agent squad during feature decomposition and orchestration.

## Contents & Structure
- `specs/`: Problem statements, requirement documents, and UI mockup wireframes.
- `contracts/`: Typed data schemas, API contracts, and Finite State Machine (FSM) transition specifications generated by the System Architect persona.
- `presentations/`: Stage 1 and Stage 2 presentation deck plans, manifests, PPTX files, and exports generated by OmniDeck.

## Workflow Integration
- **Product Manager**: Deconstructs requirements into `*_functional_spec.json`.
- **System Architect**: Emits typed contracts into `contracts/*_contract.json`.
- **OmniDeck**: Stores generated presentation artifacts in `presentations/`.
