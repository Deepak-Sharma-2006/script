# Automation Scripts & Execution Harness Directory

This directory contains the operational tooling, security scanners, distributed lock managers, test runners, and multi-agent orchestrators for the Antigravity engineering platform.

## Subdirectories
- `engine/`: OmniDeck presentation synthesis engine and layout solvers.
- `orchestrator/`: Universal TaskDispatcher, SquadOrchestrator, SpecSync, and attestation engines.
- `legacy_prototypes/`: Reserved space for experimental or deprecated generation prototypes.

## Core Tooling Files
- `lock-manager.ts`: Distributed lease locking across machines and developers.
- `role-switch.ts`: True Pipeline Triple-Mode controller (Mode 1: Deep Surge, Mode 2: Portfolio Multiplexing, Mode 3: Collaborative Team).
- `secret-scanner.ts`: Pre-commit zero-secret scanner.
- `system-readiness.ts`: 7-point pre-flight system readiness probe.
- `mutation-tester.ts`: AST fault injection mutation tester (≥80% kill rate).
- `token-budget-guard.ts`: Token consumption tracker and context headroom guard.
- `skill-finder.ts`: Dynamic progressive disclosure skill discovery tool.
- `skill-creator.ts`: Automatic skill authoring and synthesis engine.
- `memory-vault.ts`: Local SQLite-backed memory vault.
- `index-reconciler.ts`: Living documentation index reconciler and conflict-free merge driver.
