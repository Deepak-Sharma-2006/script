# Shared Team Memory Directory

This directory stores cross-project, cross-developer memory records synchronized across all workstation operators in Dual-Lead or Team Mesh mode.

## Subdirectories
- `decisions/`: Cross-cutting team architectural decisions.
- `facts/`: Enterprise infrastructure and team-wide ground-truth facts.
- `handoffs/`: Operator-to-operator handoffs across workstations.
- `lessons/`: Organization-wide engineering lessons and post-mortems.
- `runbooks/`: Team-wide deployment and rollback runbooks.
