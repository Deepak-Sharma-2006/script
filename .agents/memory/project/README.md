# Project Domain Memory Directory

This directory stores project-scoped architectural records, technical facts, lessons learned, handoffs, and runbooks.

## Subdirectories
- `decisions/`: Project-specific architectural decisions.
- `facts/`: Ground-truth empirical facts about the project runtime and dependencies.
- `handoffs/`: Intra-project phase handoffs between personas.
- `lessons/`: Engineering lessons extracted from resolved bugs or performance bottlenecks.
- `runbooks/`: Operational runbooks and diagnostic procedures for the application.
