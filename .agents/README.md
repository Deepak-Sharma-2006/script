# Agentic Platform Governance & Runtime State (`.agents/`)

This directory houses the runtime state, security enclaves, memory vault, behavioral evaluation harnesses, and operational skills for autonomous agent engineering.

## Subdirectories
- `harness/`: Behavioral eval runner and golden evaluation contracts.
- `memory/`: Durable SQLite Memory Vault and file-backed memory records.
- `rules/`: Workspace invariants, security controls, and operational guidelines.
- `security/`: Dynamic security scan reports and automated penetration test artifacts.
- `skills/`: Progressive disclosure skill library covering software engineering workflows.
- `state/`: Distributed lease locks, operating mode indicators, and active token metrics.
- `hooks.json`: Lifecycle hook definitions for event-driven agent actions.
