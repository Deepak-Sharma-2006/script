# Workspace Operational Rules & Invariants

This directory contains binding operational rules and behavioral directives loaded automatically by agents during pair-programming sessions.

## Core Directives
- `anti-hallucination.md`: Zero Ghost Packages policy and strict AST package verification.
- `code-reading-rules.md`: Bounded slice-targeted reading for large files.
- `coding-standards.md`: Strict TypeScript (`strict: true`) and modern Python standards.
- `multi-operator-sync.md`: Multi-machine distributed lease locking and domain handoffs.
- `security-controls.md`: 20-point security hardening (timingSafeEqual, input sanitization).
- `token-economy.md`: Headroom management, adaptive model optimizer, and hard token ceilings.
